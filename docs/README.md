## Quy ước thêm tệp

- Mã Sd: `examples/sd/NN_topic.sd`.
- Mã Sd++: `examples/sdpp/NN_topic.sdpp`.
- Hướng dẫn tiếng Việt: `docs/vi/`; tiếng Anh: `docs/en/`.
- Tên tệp mới viết thường, không dấu, ngắn gọn; giữ nguyên tên tệp cũ để tránh hỏng liên kết.
- Mỗi chương trình mẫu nên độc lập và có mục tương ứng trong README thư mục.

## Tìm kiếm và chỉnh sửa

Dùng thanh tìm kiếm của GitHub để tìm theo tên hoặc nội dung. Mở `.sd`/`.sdpp` trong IDE bằng **Mở tệp** để chạy; có thể sửa bằng IDE hoặc trình soạn thảo văn bản. Sd và Sd++ dùng cú pháp khác nhau, hãy giữ đúng phần mở rộng và dấu kết thúc lệnh của từng ngôn ngữ.
