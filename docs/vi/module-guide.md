# Hướng dẫn học theo module (Tiếng Việt)

Dưới đây là mô hình học theo module giúp repo phát triển thành khóa học dài hạn thay vì chỉ là các ví dụ ngắn rời rạc.

## Module 1 — Làm quen với repo

- Mở IDE
- Chạy ví dụ mẫu
- Đọc tab Vấn đề
- So sánh đầu ra và lỗi

## Module 2 — Cú pháp cơ bản của Sd

- Import
- `main`
- Biến
- Toán tử
- In ra màn hình

## Module 3 — Cú pháp cơ bản của Sd++

- `ssta`
- `define`
- `main`
- `ids.pri`
- `$` và `##`

## Module 4 — Bài tập logic và quyết định

- So sánh giá trị
- Nhánh đơn và nhánh kép
- Sử dụng ví dụ mới cho từng kiểu quyết định

## Module 5 — Có lặp lại và kiểm tra nhiều lần

- vòng lặp đơn giản
- lặp có điều kiện
- chạy và sửa từng bước

## Module 6 — Tạo mini project

- máy tính
- báo cáo số liệu
- tính tiền
- quản lý dữ liệu nhỏ

## Module 7 — Cách tổ chức repo cho người học

- Tệp và folder theo mục tiêu
- README theo từng folder
- Mỗi bài có tên, nội dung, kết quả mong muốn
- Tạo danh mục theo cấp độ từ dễ đến nâng cao

Mỗi module nên có ít nhất 1 ví dụ và 1 bài tập nhỏ. Sau đó, người học có thể đưa ví dụ vào repo theo đúng quy ước đặt tên đã thống nhất.
