# Learn Sd / Sd++ (English)

Welcome! This is the English learning path and documentation index for this repository. Sd/Sd++ use project-specific syntax and are **not C/C++**. The browser IDE in this repository contains the interpreter used by these examples.

## 1. Get started

1. Open [`Sd IDE.html`](../../Sd%20IDE.html) in a modern browser.
2. Select **Open file** and load a `.sd` or `.sdpp` sample from `examples/`.
3. Select **Run** to execute, or **Debug** to step through the program.
4. If the program uses `ipt`, enter input in the **Input** tab and run it again.

## 4. Add lessons

Keep each sample as a standalone file: Sd in `examples/sd/`, Sd++ in `examples/sdpp/`. Use lowercase, ASCII names with an order number and update the corresponding README. Do not mix the `ed`, `$`, and `##` syntax markers.
