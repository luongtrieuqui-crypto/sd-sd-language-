# Module guide for learning (English)

This module-based plan helps turn the repository into a longer learning path instead of a set of disconnected examples.

## Module 1 — Get familiar with the repo

- Open the IDE
- Run sample files
- Inspect the Issues tab
- Compare output and errors

## Module 2 — Basic Sd syntax

- Import statements
- `main`
- Variables
- Operators
- Output statements

## Module 3 — Basic Sd++ syntax

- `ssta`
- `define`
- `main`
- `ids.pri`
- `$` and `##`

## Module 4 — Decision logic

- Compare values
- Single branches and alternatives
- Create examples for each decision pattern

## Module 5 — Repetition and loops

- Simple loops
- Condition-based repetition
- Step through execution while debugging

## Module 6 — Mini projects

- Calculator
- Report generation
- Cost calculation
- Small data management demo

## Module 7 — Organization for learners

- Group files by purpose
- Keep a README in each folder
- Give each lesson a title, task, and expected outcome
- Sort content from easy to advanced

Each module should include at least one example and one small exercise. Then learners can add their own files to the repository according to the agreed naming convention.
