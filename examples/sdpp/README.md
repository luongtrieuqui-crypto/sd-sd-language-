# Ví dụ Sd++

Các tệp trong thư mục này dùng cú pháp Sd++. Mỗi tệp là một chương trình độc lập, kết thúc bằng `##`, tên theo mẫu `số-thứ-tự_chủ-đề.sdpp`.

| Tệp | Nội dung |
|---|---|
| [`01_hello_world.sdpp`](01_hello_world.sdpp) | In lời chào. |
| [`02_basic_math.sdpp`](02_basic_math.sdpp) | Khai báo biến và tính tổng. |
| [`03_rectangle_area.sdpp`](03_rectangle_area.sdpp) | Tính diện tích hình chữ nhật. |

Để thêm ví dụ, dùng số tiếp theo và tên chủ đề ngắn, dễ tìm.
