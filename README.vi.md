# Ngôn ngữ lập trình Sd / Sd++

Chào mừng bạn đến với repository học tập Sd/Sd++. Chọn ngôn ngữ để đọc hướng dẫn đầy đủ:

- 🇻🇳 **[Học Sd / Sd++ bằng tiếng Việt](docs/vi/README.md)**
- 🇬🇧 **[Learn Sd / Sd++ in English](docs/en/README.md)**

## Bắt đầu nhanh

Mở [`Sd IDE.html`](Sd%20IDE.html), chọn **Mở tệp**, rồi mở ví dụ trong [`examples/sd/`](examples/sd/) hoặc [`examples/sdpp/`](examples/sdpp/). Chạy thử bằng nút **Chạy**. Hướng dẫn học, lộ trình, cú pháp nhập môn, cách gỡ lỗi và tài liệu tham khảo nằm trong hai README theo ngôn ngữ ở trên.

Sd/Sd++ là cú pháp riêng của dự án, không phải C/C++. Mã mẫu và tài liệu tham khảo được chia theo thư mục để dễ tìm, sửa và học từng phần.
